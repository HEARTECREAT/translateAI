# translateAI
# AI-Powered Translation & UX Security Research 🔍

Проект представляет собой веб-приложение для мгновенного фото-перевода текста с использованием AI. 
Проект создан в **образовательных целях** для демонстрации работы браузерных API и исследования аспектов кибербезопасности.

## 🚀 Функционал
- **AI Text Recognition**: Использование камеры для захвата текста (имитация).
- **Context Awareness**: Определение региона через Geolocation API для точного перевода.
- **Data Integration**: Передача логов и медиаданных через Discord Webhooks для мониторинга активности системы.

## 🛠 Технологии
- **Frontend**: HTML5, CSS3 (Modern UI), JavaScript (ES6+).
- **APIs**: MediaDevices API (Camera/Audio), Geolocation API.
- **Backend-less**: Прямая интеграция с Discord API.
